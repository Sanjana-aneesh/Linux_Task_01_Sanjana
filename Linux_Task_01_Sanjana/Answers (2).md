### 1. What is Linux?
Linux is a free and open source operating system. Unlike Windows which is owned by Microsoft, Linux is available for anyone to use, modify and share. It was created by Linus Torvalds in 1991 and today it powers everything from personal computers to servers, smartphones and supercomputers.

### 2. Why is Linux important in Cyber Security?
Linux is the backbone of cybersecurity because almost all security tools like Nmap, Metasploit, Wireshark and Burp Suite are built for Linux. Most web servers and cloud systems also run on Linux so understanding it helps you know how attacks happen and how to defend against them. Kali Linux is specifically designed for penetration testing and ethical hacking.

### 3. Difference between Linux and Windows

| Feature | Linux | Windows |
|---------|-------|---------|
| Cost | Free and open source | Paid license |
| Security | More secure, fewer viruses | More targeted by malware |
| Customisation | Highly customisable | Limited customisation |
| Usage | Servers, hacking, development | General home and office use |
| Terminal | Very powerful | Limited command line |
| Privacy | No data collection | Collects user data |

### 4. What is a Linux Distribution?
A Linux distribution (or distro) is a version of Linux that comes packaged with different software, tools and desktop environments. The core Linux kernel is the same but each distro is customised for different purposes. For example Kali Linux is built for cybersecurity, Ubuntu is built for everyday desktop use, and Ubuntu Server is built for web servers.

### 5. Why do Ethical Hackers prefer Linux?
Ethical hackers prefer Linux because it gives them complete control over the system, comes with hundreds of pre-installed security tools (especially in Kali Linux), and is more stable and lightweight than Windows. Linux also has a powerful terminal that lets hackers automate tasks with scripts. Since most target systems like servers and IoT devices also run Linux, knowing Linux makes it easier to find and exploit vulnerabilities.
